# Portfolio MVP

A one-page personal portfolio built with plain HTML, CSS and JavaScript.

## Files

- `index.html` — page structure and content
- `style.css` — visual design and responsive layout
- `script.js` — minimal JavaScript

## Before publishing

Replace these placeholders in `index.html`:

- `Your Name`
- `YN`
- `your.email@example.com`
- LinkedIn URL
- GitHub URL

Project GitHub links are already included.

## Design goal

The site is intentionally small: one page, three featured projects, skills,
about section, and contact links. It is designed to be easy to maintain and
appropriate for a Game Developer / Software Engineering portfolio.
